# Yandex GO — Такси қызметін басқару жүйесі
## 1. Жоба туралы
    Yandex GO — Java тілінде жасалған такси қызметін басқаруға арналған оқу жобасы.
    Мақсаты: объектіге бағытталған бағдарламалау (OOP) принциптерін қолданып,
    жолаушы, жүргізуші, автокөлік және сапар арасындағы байланысты ұйымдастыру.
## 2. Негізгі мүмкіндіктер
    - Жолаушы мен жүргізушіні байланыстыру.
    - Economy, Comfort, Business тарифтерін таңдау.
    - Қашықтық пен тариф бойынша сапар бағасын есептеу.
    - Сапар туралы ақпаратты сақтау.
    - Жүргізушінің орташа рейтингін жаңарту.
