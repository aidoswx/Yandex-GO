# Yandex-GO
# Жоба Туралы - Жүйе сапарға қатысты негізгі нысандарды біріктіреді. Жолаушы сапар сұратады, тариф таңдалады, ал `PriceCalculator` сапар бағасын есептейді. `RatingService` жүргізуші рейтингін жүргізіп, жаңа бағаларды орташа көрсеткішке қосады.
# Негізгі мүмкіндіктер
  - Economy, Comfort және Business тарифтері;
  - сапар құнын қашықтық пен тарифке сүйеніп есептеу;
  - сапарға баға берілгеннен кейін жүргізушінің орташа рейтингін жаңарту;
  - сапар, жолаушы, жүргізуші және көлік нысандарын байланыстыру.
