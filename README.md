# Yandex GO — Такси қызметін басқару жүйесі
## 1. Жоба туралы
    Yandex GO — Java тілінде жасалған такси қызметін басқаруға арналған оқу жобасы.
    Мақсаты: объектіге бағытталған бағдарламалау (OOP) принциптерін қолданып,
    жолаушы, жүргізуші, автокөлік және сапар арасындағы байланысты ұйымдастыру.
## 2. Негізгі мүмкіндіктер
    - Жолаушы мен жүргізушіні байланыстыру.
    - Economy, Comfort, Business тарифтерін таңдау.
    - Қашықтық пен тариф бойынша сапар бағасын есептеу.
    - Сапар туралы ақпаратты сақтау.
    - Жүргізушінің орташа рейтингін жаңарту.
## 3. Қолданылған технологиялар
    - Java — негізгі бағдарламалау тілі.
    - OOP — объектіге бағытталған бағдарламалау.
    - Git — код нұсқаларын басқару.
    - GitHub — жобаны сақтау.
    - UML — кластар арасындағы байланысты көрсету.
## 4. Жүйенің архитектурасы
    Жүйе бірнеше өзара байланысқан кластан тұрады. Passenger сапар сұратады, Ride сапар мәліметтерін біріктіреді, 
    PriceCalculator бағасын есептейді, ал RatingService жүргізушінің рейтингін жаңартады.
## 5. Негізгі кластар
| Класс           | Қызметі                          |
|-----------------|---------------------------------|
| Driver          | Жүргізуші мәліметтері мен рейтингі |
| Passenger       | Жолаушы мәліметтері             |
| Car             | Автокөлік туралы ақпарат        |
| Ride            | Сапар туралы ақпарат            |
| PriceCalculator | Сапар бағасын есептеу           |
| RatingService   | Жүргізуші рейтингін жаңарту    |
## 6. Жүйенің жұмыс істеу алгоритмі
    - Жолаушы сапар сұратады.
    - Жүргізуші мен көлік анықталады.
    - Жолаушы тариф таңдайды.
    - Сапар қашықтығы енгізіледі.
    - Жүйе сапар бағасын есептейді.
    - Сапар объектісі құрылады.
    - Жолаушы баға бергеннен кейін жүргізушінің рейтингі жаңартылады.
## 7. Тарифтер жүйесі
| Тариф    | Сипаттамасы           |
|----------|----------------------|
| Economy  | Ең арзан тариф        |
| Comfort  | Жайлылығы жоғары тариф |
| Business | Премиум тариф         |
